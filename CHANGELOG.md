## [1.2.0] — аудит: волны 1–3

Итог аудита 2026-09-20 (119 находок: отчёт в `.audit/tproxy-relay/2026-09-20/`).

### Исправлено
- **REL-001 (critical):** утечка pending-зарядов при закрытии сессии —
  гарантированный сам-DoS даунлинк-гейта за часы-дни штатной работы.
  Закрытие сессии теперь возвращает все заряды и pooled-буферы; сборка
  батча перепроверяет живость сессии; `ReleaseAll` идемпотентен и под замком.
- websocket-lanes: подключение сокета лейна для никогда не открывавшегося
  лейна обрывало соединение — лейн теперь рождается вместе с сокетом.
- PERF-002: бюджет памяти не соответствовал `mem_limit` — OOM-kill всех
  клиентов разом. Теперь: pending 256 МиБ, `mem_limit: 1g`, GC-лимит 75%.
- CFG-001: healthcheck mtproxy был вечно failing (bashism в dash) — заменён
  на curl по stats-порту; релей ждёт здорового бэкенда при старте.
- REL-002: супервайзер mtproxy respawn-ит упавших детей (kill -0 вместо
  доверия pid-файлу).
- REL-003/005/008/010/011/013: бот переживает битые апдейты и уважает 429
  retry_after; тихая потеря кадров логируется; upstream-ответы и CTS
  освобождаются; реапер защищён от исключений.
- API-004/REL-016: гонка выделения backend-порта устранена (UNIQUE-индекс
  + retry); API-003: миграции схемы через PRAGMA user_version.
- REL-007: token.key пишется атомарно; битый ключ даёт внятную инструкцию.
- SEC-001: админ-листенер по умолчанию 127.0.0.1 (снаружи — только явно).
- API-005: секрет в Admin API раскрывает строго `?reveal=1`.
- DOCS-013/014, CFG-002/003/004, DEP-002/003/005, CFG-006, PERF-007,
  PERF-008, API-006/007/008/009, REL-015, SEC-003/005, REL-014/017,
  DOCS-001: см. `.audit/.../PLAN.md`, волны 1–2.

### Добавлено
- Интеграционные тесты реального стека: Admin API, HTTP-граница, оба
  WebSocket-носителя (TEST-001/002/003) — плюс найденный ими фикс.
- Протокольные отказы под ассертами: dup-seq, чужой курсор, конкурентный
  uplink, dial-кап, MaxBatchFrames (TEST-006/012).
- PERF-001/003/004/005/010: пулы батчей/буферов, гранты без O(N)-скана,
  /up без двойной буферизации.
- PERF-006: SQLite WAL + батч-UPSERT трафика одним statement.
- DEP-004/008: lock-файлы NuGet + locked-mode, global.json; CFG-007/TEST-007:
  CI собирает все образы, кеширует NuGet, снимает coverage.
- Документация: PROTOCOL.md, BASE_PATH.md, PUBLIC_SITE.md, ops-runbook,
  справочник env, CHANGELOG.
